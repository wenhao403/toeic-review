照片位於 ../word/閱讀題庫Test6/；reading-test6.json 記錄已核對的 8 張照片 SHA-256、45 個單字、題號、詞性與中文。只有螢光筆標示的英文詞彙／片語納入，變化形整理成原形；文法術語不收錄。

網站正式單字庫仍內嵌在 ../index.html 的 WORDS。此 JSON 是來源及防重複清單，網站不會自行掃描照片。新照片放好後，請在原 Codex 對話要求匯入；目前尚未設定排程。

後續匯入先比對照片內容雜湊，檢查新增／變更照片，再以 (day, word.lower()) 防止同分類重複。閱讀 Test6 使用內部分類 31，顯示名稱為「閱讀 Test6」，不可更動既有單字的識別碼；新題庫需使用新的固定分類碼。相同英文跨分類沿用既有分開統計設計。

檢查照片、題號、詞性、中文後更新 WORDS 與此清單；保留原單字與作答設定。同步更新本機預覽，測試題庫選擇、續答與紀錄，再保存。沒有指示時不推送 GitHub。正式網頁上的新單字須部署後才會出現；照片與來源清單不需要上傳 Supabase。
